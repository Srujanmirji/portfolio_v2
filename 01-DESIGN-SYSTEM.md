# Srujan Mirji Portfolio, Design System

## Direction

Build a premium, cinematic portfolio that feels like an interactive digital product.

Core qualities:
- Sexy
- Modern
- Experimental
- Editorial
- High-end
- Technical without looking generic
- Motion-led
- Strong typography
- Scroll-driven storytelling

Avoid:
- Generic developer portfolio layouts
- Excessive glassmorphism
- Random 3D objects
- Rainbow gradients
- Excessive particle effects
- Skill-logo walls
- Repetitive fade-in animations
- Template-looking cards

## Visual Language

Primary background: `#050505`
Primary text: `#F3F1EC`
Muted text: `#8A8A8A`
Accent: `#FF5A1F`
Secondary accent: `#D8FF3E`

Use orange as a controlled highlight, not as a full-page background.

## Typography

Use a strong grotesk display face for hero typography.

Recommended:
- Geist Sans
- Inter Tight
- Space Grotesk
- Neue Montreal equivalent

Hero type should be oversized and tightly tracked.

Use smaller mono or technical typography for metadata:
- Section numbers
- Dates
- Technologies
- Labels
- Coordinates
- Status indicators

## Layout

Use a 12-column desktop grid.

Keep generous negative space.

Use:
- Full viewport compositions
- Asymmetric layouts
- Oversized type
- Thin 1px borders
- Cropped imagery
- Layered UI
- Editorial alignment

Mobile must preserve the visual hierarchy rather than simply shrinking desktop.

## Navigation

Persistent minimal navigation:

SM
WORK
ABOUT
LAB
CONTACT
01 / 07

Navigation should remain visually quiet.

The active section indicator changes with scroll progress.

## Cursor

Desktop:
- Small circular cursor
- Expands on interactive elements
- Displays contextual labels such as VIEW, OPEN, EXPLORE
- Smooth interpolation
- Disable custom cursor on touch devices

## Texture

Use subtle film grain/noise at very low opacity.

Do not make the grain obvious.

## Motion Principle

Motion must communicate structure.

Every animation should answer at least one:
- Where am I?
- What changed?
- What should I look at?
- What is becoming important?
- What happens next?
