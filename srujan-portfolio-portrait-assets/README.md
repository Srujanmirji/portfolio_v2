# Srujan Portfolio Portrait Assets

Recommended usage:

1. `srujan-hero.png`
   Main hero visual. This is the strongest standalone hero composition.

2. `srujan-editorial-composite.png`
   Editorial portfolio reference/composition. Use as a visual reference, not as the final hero asset.

3. `srujan-portraits-composite.png`
   Three-pose portrait sheet:
   - large left: primary close-up / hero pose
   - upper right: arms-crossed pose
   - lower right: side/profile pose

For the actual website, prefer extracting/cropping the three poses into independent assets so GSAP can animate them separately.
